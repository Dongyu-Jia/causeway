# 情景清单与经济本质（schema-scen）

这一份回答用户的问题：「把情景都列出来，然后看看经济本质是什么，什么漏了」。
共 127 个情景，分四组：内置 13 个、历史事件 1970–2026 共 73 个、官方压力情景 10 个、长期结构主题与尾部风险 31 个。

**每个情景写四件事：**
1. **经济本质**：情景通过哪些冲击、慢变量和反馈起作用。按草表的原则，每个事件都拆成有多个历史实例的通用渠道，不设单一事件的标记。
2. **资产与定价渠道**：哪些资产受影响，经由现金流、实际利率、通胀，还是风险溢价（倍数）。
3. **时点**：新闻还是实现。资产为预期路径定价，减税、生产率浪潮在“变成预期”时就动价格。
4. **草表表达不了的部分**：对照负责人起草的季度事件表（x_q）。

**渠道代码**见 `channels.csv`（115 个渠道：每个渠道的草表字段、负责人检查清单编号、文献表列、可测代理及起始年份）。每个情景后面的渠道列表里，方括号是该渠道相对草表的状态：

| 标记 | 含义 |
|---|---|
| Y | 草表有 |
| P | 草表部分 |
| N | 草表缺 |
| S | 属 s_q 状态 |
| L | 模型学习的反馈 |
| D | 按原则分解 |
| * | 没有允许的免费测度（只能当情景假设，或靠模型的残差分布） |

**核心**渠道是情景的经济本质所在（矩阵里记 2），**次要**渠道记 1。矩阵见 `coverage.csv`。

**资产结果数字的来源。** 历史事件里引用的“OOS 残差”来自 `work/s01_episodes.json`：
- 预测值：当前传导模型（10 个同月核心因子），系数只用事件开始前的月份拟合（1985 年起的事件），喂入窗口内已实现的因子变化（oracle 宏观）。
- 残差：窗口内累计对数价格回报减去预测值。正值表示资产比宏观因子所示的更好。
- 1985 年前的事件用全样本拟合，标为“样本内”。
- 30 个样本外事件合计：美股残差平方和的 87% 与市场 P/D 的残差重合（相关 0.93）。也就是说，长周期的遗漏几乎都是倍数。
- 这些窗口有重叠，独立的事件约 22 个。
