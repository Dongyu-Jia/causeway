# 季度事件表还漏了什么（schema-scen）

用户的问题：「你能不能仔细想想还漏掉什么，这个很重要，你也许可以把情景都列出来，然后看看经济本质是什么，什么漏了」。

做法分四步：
1. 列出 127 个情景（`scenarios.md`）：内置 13 个、历史事件 73 个、官方压力情景 10 个、长期主题与尾部风险 31 个。
2. 把每个情景拆成通用经济渠道，共 115 个渠道（`channels.csv`）。
3. 逐个对照负责人起草的季度事件表（下称“草表”，即 x_q）、负责人的 13 项检查清单，以及并行中的文献表（`schema_lit/work/q_meta.json`，17:33 读取时尚未完成）。矩阵见 `coverage.csv`。
4. 用三项诊断检验哪些缺口真的影响资产价格（`work/`）。

全部只读：项目、RWT、FWT 都没有写入，Python 都以 `-B` 运行，读下载文件的脚本都以 `-I` 运行。新下载只有两类：
- 纽约联储 GSCPI 文件一个；
- FRED API 请求 43 次（元数据与 10 个序列的观测值），每 2.6 秒一次，记录中的 key 为 REDACTED。

## 0. 结论

### 0.1 草表直接覆盖约四分之一的核心渠道

127 个情景共有 566 个“核心渠道”（某情景的经济本质所在的渠道，按情景计）。按草表状态分：

| 状态 | 个数 | 占比 |
|---|---|---|
| 草表直接有（Y） | 127 | 22% |
| 按原则分解（D） | 2 | <1% |
| 模型学习的反馈（L） | 17 | 3% |
| 属于 s_q 状态（S） | 33 | 6% |
| 部分（P） | 61 | 11% |
| 缺失（N） | 326 | 58% |

- 前四项合计 32%。
- 566 个里有 57 个（10%）没有任何允许的免费测度，分布在 45 个情景里。
- 全部核心渠道都在草表里的情景只有 1 个：C04，美联储的滞胀型“不利”情景。
- 长期主题组（D 组）的中位情景，核心渠道在草表里的比例是 0。

### 0.2 缺的东西集中在六块，草表只覆盖了宏观同期变量

1. **现金流与估值**：企业盈利与利润率、企业税率、派息与回购、起点估值、长期增长预期。
2. **贴现率与风险偏好**：超额债券溢价（EBP）、期限溢价、实际利率、通胀预期、预期政策路径。
3. **投资与技术**：资本开支、AI/IT 投资、生产率、白领就业。
4. **住房、信贷与资产负债表**：
   - 房价、信贷供给；
   - 家庭与企业杠杆；
   - 商业地产；
   - 非银杠杆、融资市场压力。
5. **全球**：外需（中国）、全球利率、新兴市场压力、外国官方需求。
6. **政策与制度**：关税、政策不确定性、公共债务、行业监管、央行独立性、制裁。

### 0.3 三项诊断：哪些缺口真的动资产价格

“oracle 宏观”指喂入已实现的因子路径。系数只用训练期拟合；资产价格与估值的已实现值都不作为输入。

**（1）事件层面，长周期遗漏几乎都是倍数（s01）。**
- 30 个样本外事件（1985–2026，窗口有重叠，独立的约 22 个）中，美股残差平方和的 87% 与市场 P/D 的残差重合（相关 0.93）。负责人的假设成立。
- 纳指、工业、医疗、金融的事件残差，73%–85% 落在同一个市场倍数上。
- 能源、公用事业、REITs、黄金只有 13%–28% 落在市场倍数上，其余是行业专属的遗漏：
  - 能源：2003–08 年 +0.87、2022 年 +0.64；
  - 公用事业：2003–08 年 +0.80、2001–02 年 −0.44；
  - REITs：GFC −0.76、QE1 +0.52；
  - 黄金：2023–26 年 +0.82。

**（2）季度同期，41 个候选渠道里只有 EBP 稳定有用（s04）。**
- 做法：每个候选单独加入 10 个核心因子，看三个十年的样本外 R² 平均增量。
- **EBP**：三期都为正，+0.044 / +0.215 / +0.073。T2、T3 的 90% 区间下限为正；T2 去掉 GFC 四个季度后仍是 +0.123。
- **EPU**：T1、T2 有用（+0.080 / +0.102），T3 无（−0.004）。
- **供应链（费城联储交货时间）**：T2、T3 小幅为正（+0.038 / +0.040）。
- 其余三十多个渠道接近 0 或为负，包括同季盈利、房价、信贷、M2、财政、转移支付、服务消费。
- 行业线索（三期同号，但要考虑多重检验）：
  - 公用事业：期限溢价与天然气价格；
  - 纳指：企业股票净发行（回购）与生产率；
  - 工业：全球实际活动与交货时间；
  - 医疗：企业有效税率。

**（3）时间维度：已实现的未来值不是好的“新闻”代理（s02）。**
- 加入未来 4 个季度已实现因子之和：+0.047 / +0.128 / +0.039。90% 区间都含 0；T2 的增量去掉 GFC 后变成 −0.018。
- 加入上一季的因子变化：反而变差（−0.043 / −0.003 / −0.047）。
- 季初 P/D 水平线性加入：没有帮助（−0.151 / +0.012 / +0.007）。

**含义。** 大多数缺失渠道的价值在因子层的一致性：情景只给出一部分变量，模型要据此补全 10 个核心因子和慢变量。它们直接解释资产回报的部分很少。直接影响资产价格的缺口有三个，都与倍数有关：
- 风险偏好：可测，EBP 从 1973 年起；
- 估值状态：可测，放在 s_q；
- 长期增长预期：没有允许的免费测度。

### 0.4 草表自身的问题（§10）

- 两个有序等级字段没有可测映射，违背“LLM 输出 schema = 模型输入 schema”：`bank_stress` 0–3、`policy_stance` −2…+2。
- `supply_chain` 用 GSCPI 刻度，GSCPI 1998-01 才开始（已下载核实），1973–97 共约 100 个季度没有测量值。费城联储交货时间扩散指数从 1968-05 开始，可以补上。
- `d_shadow` 的唯一测度（Wu–Xia，亚特兰大联储）2022-02 停更，下一次零利率时没有测量值。
- `oil_q` 混合了供给与需求，资产对两者的反应相反。
- `ip_q` 只覆盖约五分之一的经济，季度模型可以直接用实际 GDP。
- `labor_supply_q` 是参与率，不含移民与人口增长。
- `bank_stress` 混合了银行偿付能力与融资市场流动性。
- 季度变化的口径（季末对季末，还是季均对季均）没有定义。

### 0.5 最小增补集（§11）

按情景覆盖贪心排序，在草表 + s_q 之上依次增加有代理的渠道，核心渠道覆盖率的变化：

| 增加的渠道数 | 覆盖率 |
|---|---|
| 0（草表 + s_q） | 32% |
| 5 | 47% |
| 10 | 56% |
| 20 | 70% |
| 30 | 80% |
| 全部 55 个有代理、且至少在一个情景里是核心的缺失或部分渠道 | 90% |

剩下的 10% 没有可测代理，只能作为情景层的显式假设。排序依赖本清单的情景构成，只能作参考。

## 1. 方法与口径

- **情景**：
  - 内置 13 个情景读自 `scenariolab/scenarios/specs/*.yaml` 的 narrative 与 causal_chain。
  - 历史事件取 1970–2026 年对美国资产有影响的事件，含海外事件。
  - 官方情景：美联储 CCAR/DFAST 与探索性分析、ECB/EBA、英格兰银行 ACS 与 SWES、NGFS/CBES 气候情景、IMF WEO 与 GFSR。官方数字只写到公开报告的量级，例如英格兰银行 2022/23 ACS 的 Bank Rate 6%、房价 −31%、商业地产 −45%。
  - 长期主题与尾部风险按任务清单展开。
- **渠道拆分**：遵守草表原则“不设单一事件标记”。每个渠道都列出它的历史实例（`channels.csv` 的 note 列）。只有一个实例的，就标为超出历史支撑，例如财政主导（只有 1942–51）、大国战争、债务通缩。
- **相关度**：2 表示经济本质所在，1 表示次要。
- **草表状态**：Y 有字段；P 字段存在，但口径或测量有缺陷；N 缺；S 应放在 s_q（季初已知的硬状态）；L 让联合模型从历史学习，不作输入；D 按原则分解。
- **代理分级**：A 表示 1973 年起可测、免费、来源在本轮允许范围内（已在项目或因子轮下载，或经 FRED API）；B 表示 1974–99 年起；C 表示 2000 年后；Pt 只有部分或间接代理；X 没有允许的免费测度。
- **新下载的限制**：因子轮已下载的 EIA、世界银行、Iacoviello、PolicyUncertainty、费城联储、密歇根、Freddie Mac 等文件可以直接读；但这些发布者不在本轮列出的下载来源中，再下载新文件需要负责人确认。

## 10. 草表字段本身的问题

1. **有序等级字段必须有可测映射**，否则 LLM 的输出与模型的输入不是同一个 schema。
   - `bank_stress`（0–3）：建议映射到几个可测序列的合成，各序列都在 1973 年前开始：
     - Baa−Aaa；
     - 商业票据−国库券（1971）；
     - 银行存款增速（H.8，1973）；
     - 贴现窗口借款（1959–2020，之后用 H.4.1 的贷款项）。

     阈值用历史分位定。参照：3 ≈ 1974、2008-Q4；2 ≈ 1984、1990–91、2023-03；1 ≈ 1998、2007-08、2011。
   - `policy_stance`（−2…+2）：建议映射到泰勒缺口（FF − 规则利率，HLW r* 按发布月、CBO 产出缺口）或实际利率 − r*，都能从 1973 年算。另增加“预期政策路径的变化”Δ(2y − FF) 作为新闻维度。
2. **`supply_chain` 的测量缺 25 年**：GSCPI 1998-01 起。用费城联储交货时间扩散指数（1968-05，已验证）在重叠期（1998–2026）映射到 GSCPI 刻度，或者直接改用交货时间。季度诊断里交货时间在 T2、T3 小幅为正。
3. **`d_shadow` 的测度 2022-02 停更**（Wu–Xia，已核实文件末行）。建议：在零利率期改用“2 年期利率 + 资产负债表”表达宽松，或者接受这个字段只在 2009–15、2020–22 有值。
4. **`oil_q` 混合供给与需求**：增加原油实物供给字段，至少用项目自己的 SVAR 冲击 e_oil_supply。
5. **`ip_q` 过窄**：季度模型可以直接用实际 GDP（1947），或同时保留两者。服务业主导的衰退（2020）与扩张，工业产出看不到。
6. **`labor_supply_q` 只是参与率**：移民与人口增长要用劳动力增长。CLF16OV、CNP16OV 每年 1 月有人口控制数断点，需要平滑。
7. **`bank_stress` 混合两件事**：银行偿付能力（信用损失、资本）与融资市场流动性（商业票据、回购、美元融资）。1970、1998、2019-09、2020-03 是后者，1986–95 是前者，2008 两者都有。建议拆成 FC06 与 M10。
8. **“文字给出时才填”的市场价格字段**（d_y10、d_spread、usd_q）要靠掩码训练让模型在缺失时推断。EBP、期限溢价也应进入这一类。
9. **单位与口径**：
   - 季末对季末，还是季均对季均（§5 TM03）；
   - 年化，还是季度变化；
   - 通胀用年化季度率时，对季度噪声很敏感，例如 2020-Q2 的服务价格。
10. **样本量提醒**：1973Q2–2026Q3 只有 214 个季度。联合模型每加一个字段都消耗自由度；10 年情景里的慢变量，独立观测只有几个周期（§3.8）。所以最小增补集（§11）比“越全越好”更重要。
