# 叙事翻译测试的输入

每个文件夹（E01–E12）是一个独立的情景。编号是随机打乱的，与时间先后无关。

| 文件 | 内容 |
|---|---|
| n1.md | 宏观叙事：政策利率、商品与服务通胀、增长、就业、油价、地缘政治、财政、疫情，带大致幅度和时间 |
| n2.md | n1 的全文，另加「金融条件」一节（10 年期国债收益率、信用利差、美元）和相应的小结 |
| n3.md | n1 的定性版本，不含任何数字 |
| prompt.md | 项目生产环境翻译器的系统提示词（`scenariolab/llm/translator.py` 的 `build_system_prompt`），引擎上下文锚定在该情景开始前的最后一个月；提示词里的日历日期都换成了下面的中性记号 |
| prompt_lwo.md | 只有个别文件夹有：同一起点的替代版本，历史月份库和传导模型换成「情景窗口以外的全部月份」 |

## 记号

- `T0` = 提示词里的「今天」，即情景开始前最后一个已观测的月份。叙事里的“第 1 个月”就是 `T0+1m`。
- `T0−5m`、`T0+1y3m`：相对 `T0` 的月份偏移（`y` 为年，`m` 为月）。
- `Y0` = `T0` 所在的日历年；`Y0−17` 指往前 17 年；“`Y0−20 年代`”指从 `Y0−20` 年开始的十年；“`Y0−3 至 Y0−2 年`”是一个年份区间。
- 提示词「其他字段」一节仍写 analogs 的格式为 `YYYY-MM:YYYY-MM`（原文未改）；示例里的 analogs 已换成上面的记号。

## 用户消息

生产环境的用户消息由 `translator._user_message` 生成，情景时长为 180 个月：

```
请把下面的叙事翻译成 180 个月的情景规格。

<narrative>
{叙事全文}
</narrative>
```
